The rig's own page — /rig

The app is the athlete's face. This page is the host's face: what this machine is serving, where the data lives, whether a Garmin key is kept — and the three decisions that only the athlete can make. It asks for nothing.

four parts

the index

the screens the rig serves — the ladder, the effort curve, the ledger, the threshold, the programmes — so the new ones are named and reachable.

the status

the version being served, the database's schema version, and where the first run stands.

the storage

where the files are, and how big the database is.

the connection

whether a Garmin key is kept, and when the log was last filled from the source.

three decisions

a race to type, a threshold to choose, a programme to adopt — listed side by side, unranked, with no vital linked to any of them. The race is typed here, because the app has no screen for it; the other two are made in the app, and this page says which screen.

and the tools

backup, restore and export live at /rig/tools, and the app's own link follows.
