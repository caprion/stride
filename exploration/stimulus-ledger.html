Where the time went — the Progress card, extended

The stimulus ledger is not a new card. It is the cut Progress wall's "Where the time went" card — the one that merges the zone card, the polarised split and the zone-time distribution — with the ledger's rows added to it: the last date each band occurred, the change against the period before, the longest run and the repeated work. Facts only: no verdict, no score, no readiness, no plan advice.

The data below is synthetic: one athlete, 25 weeks, 135 runs. The window is 7 September – 24 November 2026 — the last 12 calendar weeks through today — 58 runs, 49 h 33 m of moving time; the period it is compared against is the same span ending seven days earlier, 31 August – 17 November. There is no run above the Z4 floor for five weeks: the last one was on 20 October 2026, 35 days before the end of this period. The rules and the wording are in exploration/stimulus-ledger.md.

1The card, on the phone

Two blocks, because the two families are measured differently: by intensity (the athlete's own zones, so the three rows share the window's moving time) and by shape (the run's own structure — the longest run and the repeated work, measured by the watch's workout steps, which do not use heart rate). The coverage line sits with the rows it qualifies; the caveat sits with the absence row it qualifies. The source line is at the top of the screen, once — the model and the day it was read — and no row names the model again.

5What the card does not say

No verdict. Nothing here says the training was unbalanced, that the athlete needs threshold work, or that five weeks without a run above Z4 is a problem. The card says when the last one was and how the time moved; the reader draws the conclusion.

No advice. There is no suggestion, no "next week", no plan.

No score. No readiness, no form, no traffic light.

No miss. The absence is a date — "the last run in Z4–Z5 was on 20 Oct 2026" — and never a list of what was not done. The product's ban list has a word for that, and the ledger is the reason it does not use it.

No rest. A window with no runs says "no runs recorded": a day without a recorded run may be a forgotten watch, and the card states the record, not an inference about the athlete's week.

No zero where a value is missing. A kind with no stored model, or a window with no workout steps, has no value and says why. A measured zero — no time in Z4–Z5 — is a measurement and is shown as one.

The caveat is a fact about the measurement, not a hedge. Heart-rate time in zone counts hard running slowly and easy running generously, so the date in the Z4–Z5 row is the watch's answer. Where the watch's workout steps are available, they stand beside it as a second measurement that does not use heart rate; where they are not, the card says so instead of implying agreement.

No structure the watch did not write. The repeated-work row counts the watch's own workout steps. A run with no steps is not a run of "no repeated work" — it is a run the row cannot measure, and the row says so.

One source line per screen. The model and the day it was read are named once, at the top of the screen, and the rows stay clean — the picture carries the numbers, the source line carries the model, and the model's detail is one click away. Where an answer used a different model — a run that predates the first stored model — the row says so in place, because a silent difference would be a wrong number.
