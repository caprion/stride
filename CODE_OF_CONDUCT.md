# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

## The short version

- **Be decent.** Assume the person on the other side is doing their best with the information they have.
- **Be precise.** Critique the code, the design and the argument — never the person. "This will panic on
  an empty database" is useful; "this is careless" is not.
- **Respect the athlete's data.** This project exists because someone's own training data belongs to them.
  Never commit real data, and treat any that appears in an issue or pull request as a security incident
  worth reporting.
- **No harassment**, of anyone, in issues, pull requests, reviews or discussions.
- **No sexualised language or imagery**, no personal or political attacks, no publishing anyone's private
  information, and no deliberate disruption.

## Scope

This applies in every space the project uses — the repository, issues, pull requests, discussions, and any
release notes or documentation a contributor writes.

## Reporting

Report a problem to the maintainer privately (GitHub issues do not support private reports, so use a
security advisory or the contact in the repository's owner profile). Reports are handled confidentially.

The maintainer is expected to acknowledge a report, and to take reasonable steps to address it. If a report
concerns the maintainer themselves, it goes to GitHub's support or to the AGPL's own enforcement path.
