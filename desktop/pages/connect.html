Connect a Garmin Personal API key to bring your own runs onto this rig.

Create a key on Garmin's Personal API page. Paste the consumer key here, not the consumer secret.

After Garmin accepts it, the rig keeps it on this machine in a private file that only your account can read. It is never put in a URL or in the rig's log.
